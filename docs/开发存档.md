# 开发存档（2026-10-06 收工）

## 项目一句话

播客/音频链接或本地文件 → 自动下载、转写为带时间戳文稿、AI 梳理成结构化文章、可对话追问的自用 Web 工具（Next.js 16 + Prisma/SQLite + 百炼 ASR + DeepSeek）。

## 遗留问题与已知 bug

1. **M3 提示词回显**：文章"章节大纲"标题里混入了提示词指令文字（"按时间戳分段，每段一个小标题+要点…"）——需在 `lib/llm.ts` 的 SYSTEM_PROMPT 加"标题不要包含指令文字"
2. **ASR 专有名词错字**：如"孟岩"转写为"梦妍"（符合预期，必要时上百炼热词）
3. **对话位置待拍板**：目前在主区第三个 Tab；BibiGPT 参照图是常驻卡片，待用户决定
4. **状态语义色待确认**：成功/失败目前用中性色（失败带波浪下划线），规范色板外是否加语义红未定
5. **章节栏 hover 色**：用了 line 色 40% 透明度派生（色板外），待用户确认
6. **开发期注意（Windows）**：重启 dev 要杀 node 本体进程（占 3000 端口的），否则旧进程服务旧代码会 404/状态错乱；**改了 `next.config.ts` 触发 Turbopack 自动热重启后，动态段下的 POST 路由会集体 404（GET 正常）——必须杀进程彻底重启**；杀后台任务后 node 本体可能残留且 stdout 管道断开导致假死（端口在、不响应），需 `taskkill //PID //F //T`；curl 在这台机器对部分站点 TLS 握手失败，调试用 Node fetch；**Edge headless 截图最小窗口宽度约 500px，移动截图用 `--window-size=500,812`**（375 会被裁切，误判为布局溢出）
7. **未做**：M5 Docker 化、M6 上线（可选）、P1 自定义模板（小红书/视频脚本）、P2 说话人分离/RSS/MCP 服务化
