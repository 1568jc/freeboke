## 遗留问题与已知 bug

1. **M3 提示词回显**：文章"章节大纲"标题里混入了提示词指令文字（"按时间戳分段，每段一个小标题+要点…"）——需在 `lib/llm.ts` 的 SYSTEM_PROMPT 加"标题不要包含指令文字"
2. **ASR 专有名词错字**：如"孟岩"转写为"梦妍"（符合预期，必要时上百炼热词）
3. **对话位置待拍板**：目前在主区第三个 Tab；BibiGPT 参照图是常驻卡片，待用户决定
4. **状态语义色待确认**：成功/失败目前用中性色（失败带波浪下划线），规范色板外是否加语义红未定
5. **章节栏 hover 色**：用了 line 色 40% 透明度派生（色板外），待用户确认
6. **开发期注意（Windows）**：重启 dev 要杀 node 本体进程（占 3000 端口的），否则旧进程服务旧代码会 404/状态错乱；curl 在这台机器对部分站点 TLS 握手失败，调试用 Node fetch
7. **未做**：M5 Docker 化、M6 上线（可选）、P1 自定义模板（小红书/视频脚本）、P2 说话人分离/RSS/MCP 服务化

## 环境变量清单（.env，不入库）

- `DATABASE_URL`（SQLite 路径）
- `DASHSCOPE_API_KEY`（百炼 ASR）
- `DEEPSEEK_API_KEY`（DeepSeek 梳理/对话）
- `ASR_MODEL`（可选，默认 qwen-audio-3.1-asr-flash-filetrans）
- `LLM_MODEL`（可选，默认 deepseek-v4-flash）
- `ASR_MOCK` / `LLM_MOCK`（调试用假数据开关）

另：`.kimi-code/mcp.json` 里有 Context7 MCP 的 Key（开发工具用），已在 .gitignore 排除整个 `.kimi-code/`。
